## Slide 2: The Problem
*What issue does this project solve?*
- **Cluttered & Basic UI**: Most personal finance apps have overly simplistic interfaces that make it hard to analyze data quickly.
- **Lack of Professional Aesthetic**: Users who want a serious, "trade-desk" look are left with bright, cartoonish apps.
- **Data Density**: It's difficult to see cash flow, liquidity, and spending allocations in a single, unified view.

---

## Slide 3: The Solution
*How does your app fix the problem?*
- Built a **high-density financial tracking tool**.
- Designed with a **Bloomberg terminal-inspired aesthetic** (dark mode, monospace fonts, neon accents).
- Provides a comprehensive, single-page view of all finances for precision and clarity.

---

## Slide 4: Key Features (Part 1)
- **Live Ledger**: Comprehensive transaction tracking with a dynamic running balance.
- **Record Transaction**: Manual entry interface with real-time projected liquidity (calculates impact *before* saving).
- **Cryptographic Audit Trail**: Each transaction generates a unique SHA-256 hash to ensure data integrity and prevent tampering.

---

## Slide 5: Key Features (Part 2)
- **Spend Allocation Analytics**: Interactive visual heat bars that break down spending by category (e.g., Tech, Food, Transit).
- **Advanced Filtering**: Instantly search transactions or filter by specific types (Income, Expense, Transfer).
- **CSV Export**: One-click data export for external analysis in Excel or other tools.

---

## Slide 6: Technology Stack
*The modern tools used to build the application.*
- **Frontend Framework**: Next.js (App Router) & React
- **Language**: TypeScript (for type safety and reliability)
- **Styling**: Tailwind CSS (for rapid, responsive design)
- **Icons**: Lucide React
- **State Management**: React Hooks (useState, useMemo)
